Промпт 1: Общая постановка задачи
"Напиши на C++ модульную программу для работы с массивом целых чисел. Задание: заменить все элементы, являющиеся числами Фибоначчи, на результат рекурсивного вычисления факториала этого элемента, и найти сумму всех изменённых элементов. Требования: оформить логическую функцию isFibonacci, рекурсивную функцию factorial, создать модульную структуру с минимум 4 модулями, написать тесты для каждой функции, добавить обработку переполнения для факториала."

Промпт 2: Модуль математических утилит (math_utils)
"Напиши на C++ модуль math_utils с рекурсивной функцией factorial(int n, int& result), которая вычисляет факториал числа и возвращает false при переполнении int или отрицательном n, с комментарием к функции."

Промпт 3: Модуль проверки чисел Фибоначчи (fibonacci)
"Напиши на C++ модуль fibonacci с логической функцией isFibonacci(int n), итеративной, с обработкой отрицательных значений и защитой от переполнения при больших n."

Промпт 4: Модуль ввода-вывода (array_io)
"Напиши на C++ модуль array_io для работы с динамическими массивами. Функции: createArray (выделение памяти), deleteArray (освобождение), inputArray (ввод с клавиатуры с обработкой ошибок) и printArray (вывод с заголовком)."

Промпт 5: Модуль обработки массива (array_processor)
"Напиши на C++ модуль array_processor с функцией processArray, которая заменяет элементы-числа Фибоначчи их факториалами с использованием isFibonacci и factorial, считает сумму изменённых элементов в long long и количество замен, пропущенных из-за переполнения."

Промпт 6: Главный модуль (main)
"Напиши главный файл main.cpp, который запрашивает размер массива с проверкой ввода, вызывает ввод, выводит исходный массив, выполняет замену, выводит итоговый массив, сумму изменённых элементов и предупреждение о переполнении."

Промпт 7: Тесты
"Напиши тесты для каждой функции на assert (factorial включая 0!, 1!, 5!, 12!, переполнение на 13 и отрицательные; isFibonacci для простых и составных случаев; processArray для обычного массива и массива с переполнением) и оформи протокол тестирования в tests.txt."

Промпт 8: README и журнал промптов
"Оформи README.md с описанием задания, структуры проекта, сборки через CMake и g++, примером работы, и журнал промптов в txt."
